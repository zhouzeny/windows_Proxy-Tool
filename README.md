# TaskFlow — Windows 桌面待办工具

> 当前阶段：产品设计 + 可交互 Demo（未开始编码实现）

TaskFlow 是一款面向中文个人用户的 Windows 桌面待办工具，核心主张是 **三秒记下、关掉不丢、到点就响**。
MVP 采用单机免登录形态，不包含账号、云同步与协作。

## 运行 Demo

直接用浏览器打开 `demo/taskflow-demo.html` 即可，无需安装依赖或启动服务。

- 纯前端实现，数据为内存模拟数据，刷新页面即重置
- `Ctrl+Alt+N` 快速添加 · `Ctrl+F` 搜索 · `Ctrl+Z` 撤销 · `Esc` 关闭面板
- 右上角「模拟提醒」可预览到点通知的交互
